# 🚁 Pulverização Aérea — I Olimpíada Baiana de Drones

Projeto desenvolvido para a **I Olimpíada Baiana de Drones**, realizada pelo **Instituto Federal Baiano — Campus Guanambi**.

## 📖 Sobre a Olimpíada

A **I Olimpíada Baiana de Drones** tem como objetivo estimular o desenvolvimento de habilidades relacionadas às áreas **STEAM** — Ciência, Tecnologia, Engenharia, Artes e Matemática — entre estudantes e professores.

O evento promove a troca de experiências e conhecimentos por meio de:

* Competições com drones;
* Oficinas práticas;
* Palestras;
* Atividades relacionadas à robótica educacional;
* Discussões sobre tecnologias aplicadas aos drones.

As atividades contam com a participação de profissionais e especialistas da área.

## 🎯 Prova de Pulverização Aérea

Na prova de **Pulverização Aérea**, a equipe deve controlar uma aeronave para realizar uma missão de pulverização utilizando água.

O drone deve:

1. Decolar de uma área previamente definida pela organização;
2. Deslocar-se até uma das plantas cenográficas;
3. Posicionar-se corretamente sobre o alvo;
4. Realizar a pulverização com água;
5. Acionar os sensores presentes nas folhas da planta.

## 🌱 Sistema de Detecção

Cada planta cenográfica é composta por **duas folhas**, sendo que cada uma possui **três sensores**, totalizando **seis sensores por planta**.

Os sensores são responsáveis por detectar a deposição da água durante a pulverização. Quando um sensor identifica corretamente a presença de água, sua respectiva **lâmpada indicadora é acionada**, permitindo verificar visualmente se o alvo foi atingido.

## 🏆 Objetivo

O principal objetivo da equipe é desenvolver uma solução capaz de realizar a missão de pulverização de forma **precisa, controlada e eficiente**, atingindo corretamente os sensores presentes nas plantas cenográficas durante a prova.
